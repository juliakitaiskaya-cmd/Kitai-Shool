# UI Kit — Маркетинговый сайт Kitai School

Воссоздание лендинга `kitai-school.ru`: тёплая «бумажная» эстетика, высококонтрастный serif с курсивными акцентами, кирпично-красные CTA, доказательная подача через цифры.

## Запуск
Откройте `index.html` — одностраничный лендинг со всеми секциями. Прокручиваемая страница (не интерактивный флоу): кнопки — заглушки `href="#"`.

## Компоненты
| Файл | Что внутри |
|---|---|
| `Chrome.jsx` | `SiteHeader` (логотип + навигация + Telegram-CTA, sticky с блюром), `SiteFooter` (тёмный, контакты + лицензия) |
| `Sections.jsx` | `Hero`, `Methodology` (4 пункта с римскими цифрами), `Stats` (100% / 80% / 20), `Formats` (4 тарифные карточки), `Comparison` (Kitai vs обычное обучение), `Team`, `Quote` (тёмная цитата), `FinalCTA` (с иероглифом-печатью) |
| `site.css` | Все стили кита поверх токенов из `../../colors_and_type.css` |

## Ключевые паттерны
- **Заголовок с курсивным акцентом** (`<span className="italic">`) — фирменный приём бренда.
- **Eyebrow** над каждым заголовком (Inter, капс, трекинг).
- **Карточки** — белые, скруглённые 22px, мягкая тёплая тень.
- **Тарифные карточки** с галочками (✓ кирпичного цвета) и крупной serif-ценой.
- **Сравнительная таблица** — кирпичная колонка «мы» vs приглушённая «они».
- **Чередование фонов** секций `cream` / `cream-2` (`.alt`).
- Тёмный футер на `--ink`.

## Заметки
- Фото — из `assets/` (основатель, команда). Логотип — `assets/kitai-logo.svg`.
- Это визуальное воссоздание ключевых секций, не полная копия всех блоков сайта (опущены FAQ, отзывы-карусель, галерея HSK, расписание групп — добавляются по тем же паттернам).
- Шрифты подгружаются с Google Fonts (best-match подстановка — см. корневой README).
