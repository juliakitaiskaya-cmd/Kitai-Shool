# UI Kit — Учебная платформа Kitai School

Воссоздание личного кабинета ученика (`method.kitai-school.ru`): тёплый, дружелюбный learning-интерфейс с фиксированным иконочным сайдбаром и кремовым контентом.

## Запуск
Откройте `index.html`. Кликабельный прототип:
- **Сайдбар** слева переключает разделы; «Учить» открывает хаб тренажёра.
- В хабе **«Учить»** карточка **«Карточки»** открывает экран флеш-карты.
- На флеш-карте: **«Повтор»** показывает AI-разбор произношения (тоны + оценка + подсказка); **«Знаю» / «Сложно»** возвращают в хаб.

## Компоненты
| Файл | Что внутри |
|---|---|
| `Sidebar.jsx` | `Sidebar` — вертикальная иконочная навигация (эмодзи + подпись, активная «таблетка» `#FFF0E0`) |
| `Screens.jsx` | `Header` (приветствие + Поддержка + streak), `Dashboard` (Главная), `Learn` (хаб тренажёра), `Flashcard` (карточка + AI-произношение) |
| `platform.css` | Все стили кита поверх токенов из `../../colors_and_type.css` |

## Покрытые паттерны
Сайдбар-навигация · карточки с заголовком/текстом/CTA · primary/success/ghost/soft кнопки (pill) · карточка ежедневной цели с кольцом прогресса · плитки статистики · прогресс-бар с легендой · чипы-тогглы · поле поиска · сетка режимов тренажёра · флеш-карта с иероглифом/пиньинем · блок AI-оценки тонов · cream-подсказка.

## Заметки
- Иконки — **эмодзи**, как в оригинале (осознанный дружелюбный тон). Не заменять на линейные SVG.
- Разделы «Слова / Путь / Рост / Чат» в этом ките ведут на дашборд (заглушка) — добавьте экраны при необходимости.
- Это визуальное воссоздание, не продакшн-логика.
