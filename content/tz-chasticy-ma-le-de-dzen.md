# ТЗ на статью для Дзена: «Частицы 吗, 了, 的: короткий разбор»

> **Методика:** `tripl` + матрица инфо-триплетов + шаблон `tz-shablon-dzen.md`.
> **Канал:** Дзен, Kitai School. Автор — Юлия Горяина (от первого лица).
> **Тип:** информационно-практическая (грамматика: служебные частицы). Рубрика «Язык».
> **Ступень Ханта:** 1–2. **Формат:** лонгрид + обложка + 3 визуала (1 анимация).

## 1. Тема и запросы
- **Главный запрос:** частицы в китайском / 吗 了 的 разница.
- **Близкие КС:** частица 吗 · частица 了 · частица 的 · служебные частицы китайского · как использовать 的.
- **Отстройка:** три самые частые частицы разобраны вместе и коротко — по одной понятной работе на каждую, без грамматических дебрей.

## 2. Матрица триплетов
| Субъект → предикат → объект | Приоритет | Куда |
|---|---|---|
| Частица 吗 (ma) → превращает → утверждение в вопрос (да/нет) | ОБЯЗАТ | H2-1 + анимация |
| 吗 → ставится → в конце фразы, порядок слов не меняется | ОБЯЗАТ | H2-1 |
| Частица 了 (le) → маркирует → завершённость действия (我吃了) | ОБЯЗАТ | H2-2 + анимация |
| 了 → также маркирует → изменение состояния (下雨了 — пошёл дождь) | ОТСТРОЙКА | H2-2 |
| Частица 的 (de) → связывает → определение и слово (принадлежность/признак) | ОБЯЗАТ | H2-3 + инфографика + анимация |
| 的 → схема → X + 的 + существительное (我的书, 红色的车) | ОБЯЗАТ | H2-3 |
| Три частицы → делают → три разные работы: вопрос / завершённость / связка | ГЛАВНАЯ ОТСТРОЙКА | обзор-инфографика |
| Частица → это → «завершающий штрих», оживляющий фразу | приём | финал/идиома |

## 3. Структура
H1 → обложка → хук («…Давайте разбираться») → Кому полезна → Что вы узнаете (3) → крючок → обзор-инфографика → анимация →
- H2-1. 吗 — превращает в вопрос.
- H2-2. 了 — завершённость и изменение.
- H2-3. 的 — склеивает слова (инфографика).
- H2-4. Как не путать (коротко).
Подпись + хэштеги. Идиома-финал.
**Объём:** 5000–7000 знаков (короткий разбор).

## 5. Готовые блоки
- **Хук:** «Три коротких словечка — 吗, 了, 的 — встречаются в китайском на каждом шагу. Они крошечные, но именно они превращают набор слов в живую фразу: задают вопрос, показывают, что дело сделано, склеивают слова между собой. Давайте разбираться.»
- **Идиома:** 画龙点睛 (huà lóng diǎn jīng — «дорисовать зрачки дракону», решающий штрих); подпись 加油！
