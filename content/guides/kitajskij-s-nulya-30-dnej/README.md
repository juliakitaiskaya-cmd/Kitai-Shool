# Гайд «Китайский с нуля: план на первые 30 дней»

Готовый файл: **`kitajskij-s-nulya-30-dnej.pdf`** — 12 страниц A4, около 700 КБ. Шрифты вшиты в PDF, поэтому он одинаково выглядит на любом устройстве и нормально печатается.

Для чего: лид-магнит для канала и сайта. Отдаётся за подписку, вкладывается в письмо после заявки, раздаётся на вебинарах. Печатать можно на обычном чёрно-белом принтере — макет не рассыпается, чек-лист остаётся читаемым.

## Как пересобрать

```bash
node render.cjs                    # соберёт PDF рядом
node render.cjs --out draft.pdf
```

Нужны Node с playwright (chromium). Текст и вёрстка — в `guide.html`, это обычная страница: открывается в браузере и правится как HTML.

Устройство макета: каждая страница — блок `.page` ровно 210×297 мм со своими полями, у `@page` поля нулевые. Chromium печатает то же, что видно на экране, без сюрпризов с переносами. Плата за это — следить, чтобы содержимое страницы не выезжало за нижнюю линейку.

Проверить переполнение после правок текста:

```bash
node check-fit.cjs
```

Скрипт печатает, сколько миллиметров свободно на каждой странице до подвала. Отрицательное число — содержимое выехало, надо сокращать текст или переносить блок на соседнюю страницу.

## Шрифты

`fonts/` и `fonts.css` собираются скриптом `build-fonts.py`: Cormorant Garamond, Inter и крошечный поднабор Noto Serif SC — только те иероглифы, что реально есть в тексте (сейчас 59). Скрипт сам вычитывает их из `guide.html`, так что после правок достаточно прогнать его заново:

```bash
python3 build-fonts.py
```
