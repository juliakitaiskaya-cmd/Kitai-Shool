# Гайд «Китай без культурного шока: 50 фактов»

Готовый файл: **`50-faktov-o-kitae.pdf`** — 10 страниц A4, около 1,3 МБ. Шрифты вшиты, печатается на обычном принтере.

Сделан из присланного текстового файла «50 фактов о Китае, которые помогут избежать культурного шока»: там был сплошной список без разделов и вёрстки, обращение на «ты». Здесь материал переработан под наш формат.

## Что изменилось против исходника

- **Текст написан заново.** Формулировки свои, обращение на «вы», без «моветона», «must-have» и «забудь про рукопожатия». Из исходника взяты сами факты, а не фразы.
- **Появились разделы.** Пятьдесят пунктов разложены по семи темам, внутри каждой — карточки. Читать можно с любого места, а не только подряд.
- **К каждому факту одно китайское слово** — иероглифы, чтение латиницей и перевод. В исходнике примеры были длинными предложениями, которые никто не запомнит.
- **Добавлена оговорка на второй странице**: всё написанное — типичная картина, а не закон, Китай разный. Без неё гайд читается как свод правил, а это неправда.
- **Два факта заменены.** «Уважение к государству» убрано: тема политическая, а мы про неё не пишем (см. `kitai-school-style-guide.md`). «Жильё дорогое» убрано как бесполезное для приезжего — вместо них добавлены «дорогу переходите внимательно: поворот направо часто разрешён» и «наличные почти не нужны, но небольшой запас держите».

## Как пересобрать

```bash
node render.cjs                 # соберёт PDF рядом
node check-fit.cjs              # покажет запас до подвала на каждой странице
python3 build-fonts.py          # пересобрать поднабор шрифтов после правки иероглифов
```

Устройство то же, что у гайда `kitajskij-s-nulya-30-dnej`: `guide.html` — обычная страница, каждый разворот отдельным блоком 210×297 мм, chromium печатает её в PDF. Карточки фактов лежат в сетке `.facts` по две в ряд и растягиваются на всю высоту полосы, поэтому на страницах с шестью карточками они просто выше — переверстывать ничего не нужно.
