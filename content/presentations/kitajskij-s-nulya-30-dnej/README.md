## Про шрифты

В PDF-гайде стоят фирменные Cormorant Garamond, Inter и Noto Serif SC. В презентации их нет намеренно: PowerPoint берёт шрифты с компьютера того, кто открывает файл, а этих шрифтов там обычно не установлено — текст поехал бы. Поэтому взяты **Cambria** в заголовках и **Calibri** в тексте: они есть в любом Office, а по характеру близки к фирменной паре «серьёзный серифный заголовок + спокойный текст». Иероглифы PowerPoint подставит системным китайским шрифтом.

Если фирменные шрифты установлены на компьютере, где идёт показ, замените их в `build.cjs` (`HEAD` и `BODY`) и пересоберите.

## Как пересобрать

```bash
node build.cjs                      # соберёт .pptx рядом
node build.cjs --out draft.pptx
```

Нужен `pptxgenjs` (`npm install pptxgenjs`); путь к нему берётся из переменной `PPTX_PATH`, иначе используется путь по умолчанию в начале скрипта.

Тексты, порядок слайдов и заметки — всё в `build.cjs`, каждый слайд отдельным блоком с комментарием. Цвета фирменные, из `design-system/colors_and_type.css`.

`logo-ink.png` и `logo-light.png` — логотип из `design-system/assets`, переведённый в растр (PowerPoint не понимает SVG). Светлый вариант стоит на тёмных слайдах.

## Как проверить после правок

```bash
soffice --headless --convert-to pdf kitajskij-s-nulya-30-dnej.pptx
pdftoppm -jpeg -r 100 kitajskij-s-nulya-30-dnej.pdf slide
```

Дальше просмотреть картинки: у слайдов фиксированная сетка, и если текста стало больше, он может наехать на соседний блок. Особенно это касается таблиц — их строки растут по содержимому.
