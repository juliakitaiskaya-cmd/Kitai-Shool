# Видео «Тренажёр»

Готовый файл: **`trenazhyor-1080x1920.mp4`** — 1080×1920 (9:16), 43,6 секунды, 30 кадров в секунду, H.264 плюс пустая звуковая дорожка.

Ролик построен на **настоящих скриншотах** тренажёра платформы (папка `shots/`), которые прислали из школы. Ничего не нарисовано и не придумано: названия режимов и подписи взяты прямо с экранов.

## Как идёт ролик

| Секунды | Что на экране |
|---|---|
| 0,0–4,6 | «Чем заниматься между уроками?» — в кабинете ученика есть тренажёр |
| 4,6–12,8 | **Как выучить новое?** Экран «Учить новое»: по очереди подсвечиваются «Заполни пропуск» и «Диалог» |
| 12,8–21,0 | **Как не забыть пройденное?** «Повторить пройденное»: «Карточки» и «Найти пару» |
| 21,0–26,6 | **Как потренировать навык?** «Тренировать навык»: «Собрать предложение» |
| 26,6–37,8 | **А как быть с иероглифами?** «Быстрая проверка», «Написать иероглифы», «Написание» |
| 37,8–43,6 | Финал: «Занятие собирается из вашего урока», запись в личных сообщениях, два фрагмента экранов |

Каждая карточка на экране подсвечивается красной рамкой, остальные приглушаются, снизу появляется подпись «что вы делаете в этом режиме».

## Откуда факты

Все пояснения опираются на подписи самого интерфейса:

- «Заполни пропуск — выбери слово»; «Диалог — слово в контексте»;
- «Карточки — помню / не помню»; «Найти пару — слово и перевод, на время»;
- «Собрать предложение — расставь слова по порядку»;
- «Быстрая проверка — узнаёшь иероглиф?»; «Написать иероглифы — знаки урока»; «Написание — порядок черт».

Фраза финала «занятие собирается из вашего урока» взята из экрана «Уроки» платформы: «5 предложений с конструкцией 把 — мы собрали из твоего урока» и «занятие на 8 минут уже подобрано».

Чего в ролике нет намеренно: цифр результатов, обещаний сроков, слов «лучший» и «быстро». Показано, что есть, без оценок.

## Как заменить скриншоты

Новые экраны кладите в `shots/` с теми же именами (`learn`, `review`, `skill`, `hanzi`). Если размер изменился, поправьте в `video.html` массив `SHOTS`: ширина и высота файла, а также границы карточек `y0` и `y1` в пикселях исходной картинки.

## Как пересобрать

```bash
node render.cjs                      # соберёт mp4 рядом
node render.cjs --fps 60 --out big.mp4
```

Нужны Node с playwright (chromium) и ffmpeg с libx264. Шрифты лежат локально в `fonts/`, пересобираются `python3 build-fonts.py`.
