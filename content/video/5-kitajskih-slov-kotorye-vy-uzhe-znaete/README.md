# Видео к посту «5 китайских слов, которые вы уже знаете»

Готовый файл: **`5-kitajskih-slov-1080x1920.mp4`** — 1080×1920 (9:16), 39,6 секунды, 30 кадров в секунду, H.264 + пустая звуковая дорожка (её просят Reels и VK, иначе загрузчик иногда ругается). Вес около 2,5 МБ.

Куда подходит: Reels, Shorts, VK Клипы, кружки и сторис в Телеграме. Текст не заходит на нижние 15% кадра, поэтому подписи площадок и кнопки его не закроют.

## Что в кадре

| Секунды | Сцена |
|---|---|
| 0,0–4,6 | заставка: заголовок поста и подводка |
| 4,6–10,6 | 茶 chá — чай |
| 10,6–16,6 | 台风 táifēng — тайфун |
| 16,6–22,6 | 关系 guānxi — гуаньси |
| 22,6–28,6 | 功夫 gōngfu — кунг-фу |
| 28,6–34,6 | 麻将 májiàng — маджонг |
| 34,6–39,6 | финал: kitai-school.ru и телеграм-канал |

Каждое слово держится 6 секунд: иероглиф, пиньинь, перевод и короткая карточка с историей слова. Сверху — полоса «слово N из 5», она заполняется по ходу видео. Цвета, шрифты и логотип взяты из `design-system` (кирпичный `#A41E3A`, кремовый фон, Cormorant Garamond + Inter + Noto Serif SC).

## Как пересобрать

```bash
node render.cjs                      # соберёт mp4 рядом
node render.cjs --fps 60 --out big.mp4
node render.cjs --scale 2            # 2160×3840, файл тяжелее раза в четыре
```

Нужны Node с playwright (chromium) и ffmpeg с libx264.

Как это работает: `video.html` — обычная страница, которая умеет показывать себя в любой момент времени через `window.setTime(t)`. Скрипт открывает её в chromium, перематывает по кадрам, снимает каждый кадр и отдаёт прямо в ffmpeg. Поэтому картинка не зависит от скорости машины: два рендера дают одинаковый файл.

## Как поменять текст

Всё в `video.html`:

- массив `WORDS` — иероглиф, пиньинь, перевод и текст карточки. `<b>` выделяет слово тёмным, `<span class="han">` даёт иероглифам китайский шрифт внутри русской фразы;
- `T_INTRO`, `T_WORD`, `T_OUTRO` — длительности сцен в секундах, общая длина считается сама;
- заставка и финал — блоки `intro` и `outro` тут же, рядом.

После правок стоит открыть `video.html` в браузере и в консоли подвигать `setTime(12)`, чтобы посмотреть кадр, — так быстрее, чем гонять рендер.

## Шрифты

`fonts/` и `fonts.css` собраны один раз скриптом `build-fonts.py` — страница рисуется офлайн, без обращений к Google Fonts. Если бы шрифты тянулись из сети, одна оборванная загрузка на рендере — и всё видео уехало бы в системный шрифт.

У Noto Serif SC берётся крошечный поднабор: только иероглифы, которые есть в кадре (`HANZI` в скрипте). Добавляете новое слово — впишите его иероглифы туда и прогоните `python3 build-fonts.py`.
