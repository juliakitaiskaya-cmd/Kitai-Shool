# Видео «Страница для родителей» (черновик)

Готовый файл: **`dostup-dlya-roditelej-1080x1920.mp4`** — 1080×1920 (9:16), 35,8 секунды, 30 кадров в секунду, H.264 плюс пустая звуковая дорожка. Вес около 2,8 МБ.

**Это черновик на демонстрационных данных.** Имя ученицы, группа, расписание, имена преподавателей, оценки и домашнее задание придуманы, чтобы показать макет. Перед публикацией их нужно заменить на согласованные — см. «Что заменить» ниже.

Приём взят из промо чужой школы, которое прислали для примера: мокап телефона с живым интерфейсом и рубриками «01 · ДОСТУП». Дизайн, тексты и экраны — наши.

## Как идёт ролик

| Секунды | Что на экране |
|---|---|
| 0,0–4,6 | Телефон выезжает снизу, подпись «Страница для родителей · Учёба ребёнка — всегда под рукой» |
| 4,6–11,2 | **01 · Доступ.** В переписке со школой печатается сообщение, появляется карточка со ссылкой, по ней «нажимают», адресная строка меняется на адрес страницы |
| 11,2–17,4 | **02 · Расписание.** Посещаемость 6 из 6, домашние 5 из 6, карточки занятий с отметками «был на уроке» |
| 17,4–23,8 | **03 · Оценки.** Всплывает уведомление «урок прошёл», страница прокручивается к оценкам и обратной связи преподавателя |
| 23,8–30,0 | **04 · Домашнее задание.** Что задали, до какого числа, следующий урок |
| 30,0–35,8 | Финал: «Доступ открывает преподаватель», что видит родитель и что остаётся личным, запись в личных сообщениях |

Интерфейс телефона нарисован кодом по дизайн-системе школы: кремовый фон, кирпичные акценты, зелёные отметки посещения. Ничего не снималось с экрана, поэтому правки текста и данных — это правки в HTML.

## Как пересобрать

```bash
node render.cjs                      # соберёт mp4 рядом
node render.cjs --fps 60 --out big.mp4
node render.cjs --scale 2            # 2160×3840
```

Нужны Node с playwright (chromium) и ffmpeg с libx264. Шрифты лежат локально в `fonts/`, пересобираются скриптом `python3 build-fonts.py`.

## Как устроена анимация

`video.html` — страница с `window.setTime(t)`, где собраны все состояния:

- **Сцены** перечислены в массиве `SCENES` сверху: меняете длительность — меняется весь тайминг.
- **Печать сообщения** — срез строки `MSG_TEXT` по прогрессу.
- **Нажатие** — кружок `#tap`, который увеличивается и тает.
- **Прокрутка страницы** — `translateY` контейнера `#p-parent`, два шага: к оценкам и к домашнему заданию.
- **Уведомление** `#push` всплывает перед блоком с оценками.
- Телефон всё время едва заметно покачивается, в финале уезжает вниз.
